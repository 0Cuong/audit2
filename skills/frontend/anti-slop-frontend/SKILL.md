# Anti-Slop Frontend

Before coding, write a one-line design read describing page kind, audience, visual language, and implementation foundation.

Inspect existing type, color tokens, spacing rhythm, component language, assets, and interaction patterns. For redesigns, preserve proven structure unless evidence shows it is harmful.

Avoid automatic defaults such as AI-purple gradients, centered hero plus mesh, identical feature cards, universal glassmorphism, excessive pills/shadows/radius, and animation everywhere.

Use animation only when it explains change, orientation, or deliberate delight. Prefer CSS/WAAPI where sufficient and always provide reduced-motion behavior.

Finish by checking hierarchy, optical alignment, responsive behavior, focus/keyboard behavior, empty/error/loading states, long-content resilience, contrast, and performance.
