# Visual QA

1. Start the real application.
2. Open the actual route.
3. Inspect console and network errors.
4. Check mobile, desktop, and wide layouts.
5. Exercise key interactions and deep links.
6. Check focus order and keyboard operation.
7. Test prefers-reduced-motion.
8. Capture evidence where tooling exists.
9. Fix concrete defects.
10. Repeat until remaining issues are known.

Check overflow, clipping, unstable layout, spacing, hierarchy, focus visibility, excessive motion, hover-only functionality, and long content.

Source inspection alone is not sufficient for significant UI work.
