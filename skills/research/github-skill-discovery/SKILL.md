# GitHub Skill Discovery

## Search order
1. Official documentation
2. Official/first-party repositories
3. Maintained open-source repositories
4. Strong community references
5. Experimental sources only when necessary

For each candidate check exact URL/commit, license, maintenance, compatibility, dependencies, examples, security posture, and overlap with local skills.

Prefer adapting useful knowledge into small local skills and recording provenance in skills/registry.json. Do not vendor a whole catalog without a demonstrated need.

For fast-moving libraries, verify current APIs from primary documentation before writing code.
